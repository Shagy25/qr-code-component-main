## My process

### Built with

- Semantic HTML5 markup
- CSS custom properties
- Flexbox

### What I learned

- **Flexbox:** I used `flex: 1` on the main block so it fills all the
  free space between the top of the page and the footer, and centered
  the card with `justify-content` and `align-items`.
- **Semantic HTML:** I replaced a generic `<div>` with `<main>` for
  the main page content, which helps screen readers and search engines.
- **Shadows:** I learned how to add depth to a container with
  `box-shadow`.
- **Matching a design:** I practiced matching the text wrapping to the
  design by adjusting margins.

```css
.page {
  display: flex;
  flex: 1;
  justify-content: center;
  align-items: center;
}
```
